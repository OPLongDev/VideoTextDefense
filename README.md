# 视频文字防御者 (VideoTextDefense) v1.0.0 正式发布 🎉

完全离线、本地运行的视频文字自动打码工具。逐帧识别中文文字，精准覆盖，支持 GPU 加速，绿色便携无需安装。

## ✨ 核心亮点
- **完全离线**：内置完整 OCR 模型，解压即用，无需联网下载任何文件，断网也能跑。
- **绿色便携**：所有数据（配置、日志、截图、模型）全部存放在软件根目录的 `data` 文件夹，不写 C 盘 AppData，换电脑插 U 盘就能用。
- **命中帧截图画廊**：自动保存打码前 / 打码后的整张画面，缩略图网格浏览，双击一键对比效果，方便排查打码位置。
- **字符级精准打码**：只对命中敏感词的字符做高斯模糊 / 像素化 / 纯色块处理，画面其余像素逐像素不变，不留痕迹。
- **GPU / CPU 自动切换**：默认尝试 GPU 加速，若电脑无 N 卡或无 CUDA 环境，会自动降级为 CPU 模式并弹窗提示，绝不卡死。

## 📦 安装与使用（必看！）
1. **下载**：下载下方的 `VideoTextDefense_v1.0.0_win64.zip`。
2. **解压**：**务必解压到纯英文、无空格的路径**（例如 `D:\VideoTextDefense`）。由于 Paddle 底层限制，**包含中文的路径会导致 OCR 模型无法加载**！
3. **运行**：双击 `VideoTextDefense.exe`。
4. **首次启动**：默认会尝试加载 GPU 模型，大概需要 20~40 秒初始化。如果无 N 卡，会弹窗提示降级 CPU，点击确认即可正常使用。

## ⚠️ v1.0.0 已知问题（后续版本优化）
本版本为 1.0.0 初始发布版，以下问题已被记录，将在后续版本中逐步修复：
1. **AMD 显卡（A 卡）处理速度较慢**：目前软件默认优先支持 N 卡（CUDA），A 卡只能走 CPU 推理，处理长视频会偏慢。
2. **超长视频文件名可能导致画廊不显示**：如果视频名字特别长（包含大量空格和点号），命中帧画廊可能会空着。建议将视频重命名为短名字（如 `1.mp4`）后处理。
3. **字幕渐隐时打码失效**：当视频文字透明度很低（渐隐消失阶段）时，OCR 可能会漏检，导致打码失败。目前正在优化 OCR 识别策略。
4. **长视频处理速度较慢**：处理长视频时，建议调大「跳帧间隔」或者只保留需要打码的敏感词，关闭不必要的截图保存选项。
